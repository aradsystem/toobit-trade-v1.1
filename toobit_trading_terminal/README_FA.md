# Toobit Trading Terminal

نسخه کاربردی برای ورود دستی + مدیریت خودکار پوزیشن (Python 3.11–3.13)

## نصب
```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
copy .env.example .env
python main.py
```

برای سفارش واقعی: در `.env` کلید API و `ENABLE_LIVE_TRADING=true`.

## امکانات
### اسکنر
- دوره ۲۴س / ۱س / ۴س / ۱۲س / هفته
- مرتب‌سازی: رشد، ریزش، حجم، مومنتوم

### نمودار
- کندل + حجم + EMA20/50 + باند بولینگر
- خطوط سطح پوزیشن: **ورود، SL، TP، لیکویید، قیمت لحظه**
- از تب پوزیشن‌ها: «نمایش روی نمودار» یا دابل‌کلیک

### ورود دستی
- انتخاب نماد از لیست
- بعد از سفارش (اگر در تنظیمات فعال باشد): ست خودکار SL/TP
- ذخیره اسنپ‌شات RSI / MACD / Bollinger در تایم‌های ۱م / ۵م / ۱۵م برای تحلیل بعدی نقطه ورود

### تنظیمات ترید + مانیتور
- SL/TP درصدی روی قیمت
- انتقال استاپ به سربه‌سر بعد از X٪ حرکت قیمت
- **Peak Protect**: اگر ROE از آستانه (مثلاً ۱۰۰٪) گذشت و بعد به نسبت قله (مثلاً نصف) برگشت → بستن خودکار
- مانیتور دوره‌ای پوزیشن‌های باز (قابل خاموش/روشن)

## جریان پیشنهادی شما
1. اسکنر → بیشترین رشد ۲۴س
2. تحلیل و ورود دستی Long
3. برنامه SL/TP می‌گذارد و پوزیشن را مانیتور می‌کند
4. اسنپ‌شات ورود ذخیره می‌شود تا بعداً برای اتوماتیک‌کردن نقطه ورود بررسی شود

## هشدار
معامله فیوچرز پرریسک است. ابتدا با حجم خیلی کم و بدون `ENABLE_LIVE_TRADING` تست کنید. کلید API را بدون مجوز برداشت بسازید.
